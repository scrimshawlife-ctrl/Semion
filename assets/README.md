# Assets

| File | Use |
|---|---|
| `hero.svg` | README banner |
| `og-social.svg` | 1280×640 link preview stand-in |
| `hero.jpg` | optional raster drop-in (generate locally; not required for specify) |
| `og-social.jpg` | paste into GitHub Settings → General → Social preview |

GitHub social preview API is not writable from this lane. Operator pastes `og-social.jpg` in the repo settings UI.
