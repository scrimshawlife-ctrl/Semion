# Assets

| File | Use |
|---|---|
| `hero.svg` | README banner (vector) |
| `hero.png` / `hero.jpg` | README hero raster (1600×900) |
| `og-social.svg` | 1280×640 link-preview stand-in |
| `og-social.png` / `og-social.jpg` | Settings → General → Social preview (1280×640) |

GitHub social preview **API is not writable** (REST/GraphQL/MCP). Operator pastes `og-social.jpg` in the repo Settings UI after merge.

Semion is private; GitHub only allows custom OG upload on public repos, or private repos that already have a custom image.
